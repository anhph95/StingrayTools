# ctdtools

Installable CTD downloader for NES-LTER cruise data.

```bash
pip install "ctdtools @ git+https://github.com/anhph95/StingrayTools.git#subdirectory=packages/ctdtools"
```

Command-line entrypoint:

```bash
ctd-download --help
```

The full `stingraytools` install also exposes this workflow through:

```bash
stingray ctd download --help
```
